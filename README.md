## 🛠️ Concepts & Technologies Used
* **Language:** Python 3
* **Core Concepts:** Variables, Data Types, Conditional Statements (`if-else`), Loops (`for`, `while`), Functions, Modularity
* **Modules/Libraries:** `random`, `tkinter`, `time`

## 💻 How to Run the Projects

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pragnyamekap/python-mini-projects.git
2. **Navigate into the folder:**
   ```bash
   cd python-mini-projects
3. **Run any project you want:**
   ```bash
   python 02_number_guessing_game.py

   
 **Requirements:**
  Only Python 3.x is required. Built-in modules like `tkinter`, `random`, and `time` are used, so no additional dependencies need to be installed.
